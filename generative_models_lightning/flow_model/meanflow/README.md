# MeanFlow

Vendored from `https://github.com/haidog-yaqub/MeanFlow` at commit
`18b67b25a3af86d199005023bb190024d28233e7`.

The algorithm implementation is decomposed under
`generative_models_lightning/flow_model/Flow_matching/` into path, loss,
solver, and utility components. This directory retains the upstream models,
examples, MIT license, and backward-compatible imports.

Included:

- `meanflow.py` compatibility imports
- `models/dit.py`
- example training scripts under `examples/`

Not included:

- upstream `.git` metadata
- image assets from the upstream `assets/` directory
